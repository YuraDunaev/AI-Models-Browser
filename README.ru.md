## 💡 Что умеет

### Найти нужную модель

В каталоге OpenRouter сейчас около 470 моделей, и найти среди них подходящую без фильтров
нереально. Здесь с этим помогает всё сразу:

- **Поиск** по названию и идентификатору, с подсветкой совпадений прямо в списке.
- **Фильтр по провайдеру**, если нужна конкретная контора, а не всё подряд.
- **Только избранное** — ваши звёздочки, собранные в один клик.
- **Только бесплатные** — модели с нулевой ценой.
- **Одна модель на семейство** — если в семействе десять вариантов одного и того же, останется
  самый дешёвый.
- **Модальности** — отдельно по тому, что модель принимает и что отдаёт: текст, картинки, аудио.
- **Ограничения по контексту и цене** — задали минимальное окно и максимальную цену за миллион
  токенов, получили только подходящие.

Фильтры работают вместе, а не по очереди — можно сразу задать «дороже 2 $ не показывать, вход
только текст, контекст от 100 тысяч».

### Сравнить варианты

Отметьте модели чекбоксом `⇄` (до пяти штук) и откройте окно сравнения. В каждой колонке лучшее
значение подсвечивается цветом — сразу видно, где контекст больше, где цена ниже, а где у кого
лучше ваша оценка.

### Понять, во что обойдётся запрос

Для каждой модели считается стоимость стандартного запроса на 1000 входных и 1000 выходных
токенов. Это нагляднее, чем «$0.15 за миллион», когда нужно прикинуть счёт.

### Забрать готовый код

В карточке модели лежит готовый запрос — на **cURL**, **Python** или **JavaScript**. Нажали
«Скопировать код» — вставили в свой проект. Идентификатор модели тоже копируется в один клик,
в том числе горячей клавишей <kbd>Enter</kbd>.

### Запомнить своё

- **Избранное** — звёздочка на понравившейся модели.
- **Свои оценки** — от 0,5 до 5 звёзд, с половинами. Оценки и избранное сохраняются и никуда не
  отправляются.
- **Экспорт** — текущую выдачу в JSON или CSV (CSV с BOM, чтобы Excel открывал без плясок), либо
  только избранное в CSV.

### Не терять настройки

Провайдер, язык, тема, размеры шрифтов, видимые колонки, фильтры, избранное, оценки и выбранный
вид — всё это переживает перезапуск. Приложение открывается ровно таким, каким вы его закрыли.

### Работать без интернета

Каталог кэшируется на диск, поэтому приложение стартует мгновенно и остаётся работоспособным,
даже если сеть пропала. Когда связь появится, кнопка обновления (или <kbd>R</kbd>) подтянет свежие
данные.

### Быстро

В таблице рисуются только видимые строки, поэтому список из сотен моделей листается плавно.
Перерисовка целиком не тормозит — список обновляется одной операцией с DOM.

### Управлять с клавиатуры

| Клавиша | Действие |
|---|---|
| <kbd>/</kbd> | Перейти к поиску |
| <kbd>↑</kbd> <kbd>↓</kbd> | Ходить по моделям |
| <kbd>Enter</kbd> | Скопировать id выбранной модели |
| <kbd>R</kbd> | Обновить список |
| <kbd>Esc</kbd> | Сбросить фильтры или закрыть окно |

Полный список — в настройках, там же он всегда под рукой.

### Переключить язык

Интерфейс переводится мгновенно: английский, русский, немецкий, французский, испанский, китайский.

### Поиграть

Кликните по логотипу в шапке — прилетит конфети и откроется окно «О приложении».

## 🛠 На чём сделано

| Слой | Технология | Зачем |
|---|---|---|
| Оболочка | **C# / .NET 10**, Windows Forms | Нативное окно и нативные ощущения |
| Рендеринг | **WebView2** (Chromium) | Современный CSS без собственного движка браузера |
| Фронтенд | **Чистые JavaScript и CSS** | Ни фреймворков, ни сборщика, ни `node_modules` — весь интерфейс это ~220 КБ исходников |
| Данные | **OpenRouter** `/api/v1/models` | Один запрос — весь каталог |
| JSON | `System.Text.Json` | Быстро, без лишних зависимостей |
| Хранение | JSON-файлы в `%LOCALAPPDATA%` | Понятно, легко забэкапить, база данных не нужна |
| Тесты | **xUnit** | 43 теста на разбор данных, маппинг и сохранение |

Сборки JavaScript, npm и бандлера нет вообще: файлы интерфейса встраиваются в исполняемый файл и
отдаются в WebView2 одним документом.

## 🚀 Собрать и запустить

```bash
git clone <адрес-репозитория> AI_Model_Chooser
cd AI_Model_Chooser

dotnet build -c Release
dotnet run --no-build -c Release
```

### Один файл

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Готовая программа окажется в `bin/Release/net10.0-windows/win-x64/publish/`.

### Проверки

```bash
# Тесты: разбор ответа API, маппинг, сохранение настроек
dotnet test tests/AiModelsBrowser.Tests

# Переводы: все ключи есть во всех шести языках
node wwwroot/i18n.check.js

# Переводы: нет ключей, которые никто не использует
node wwwroot/i18n.unused.check.js
```

Node-скриптам зависимости не нужны — достаточно чистого `node`.

## 🧩 Как это устроено

```
┌─────────────────────────────────────────────────────────────┐
│  C# / WinForms                                                │
│  ApiService ──► модели OpenRouter                            │
│  ModelMapper ──► DTO ──► JSON (camelCase) ──► в JavaScript   │
│  Хранение: settings.json · userdata.json · models_cache.json  │
└──────────────────────────┬──────────────────────────────────┘
                           │  сообщения в обе стороны
┌──────────────────────────▼──────────────────────────────────┐
│  WebView2 / Chromium                                         │
│  Фильтрация · сортировка · отрисовка · сравнение            │
└─────────────────────────────────────────────────────────────┘
```

- **Данные живут в C#.** Он скачивает каталог, превращает его в компактные DTO и отдаёт в
  JavaScript в том виде, в котором тот ожидает.
- **Интерфейс живёт в JavaScript.** Фильтрация, сортировка, сравнение и отрисовка — всё в браузере.
- **Обмен — один формат сообщений** в обе стороны, так что новая функция добавляется симметрично
  с двух сторон.
- **Всё внутри exe.** Никаких файлов рядом с программой, никакого локального сервера.

### Где лежат данные

Всё, что приложение сохраняет, — в `%LOCALAPPDATA%\AI Models Browser\`:

| Файл | Что внутри |
|---|---|
| `settings.json` | Тема, шрифты, провайдер, язык, колонки, вид, автообновление |
| `userdata.json` | Избранное, оценки, последние фильтры |
| `models_cache.json` | Последний скачанный каталог |

Никуда наружу эти данные не уходят. Удалили файлы — получили чистый старт.

## 📝 Что стоит знать

- Каталог приходит из **OpenRouter**. Цены, контекстные окна и наличие моделей меняются, и
  принадлежат они своим владельцам.
- Приложение **ничего не отправляет** в модели и **не просит API-ключ** — оно только читает каталог.
- Это программа **только под Windows**, кроссплатформенной версии нет.
- Данные кэшируются ради быстрого старта; <kbd>R</kbd> обновляет каталог.
